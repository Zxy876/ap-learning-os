# Materials Policy

This repository does not include generated study PDFs, textbook excerpts, AP packets, screenshots, or session evidence.

Those files are generated locally from user-provided materials and may contain copyrighted or private content. The public repository only stores:

- source code
- workflow logic
- material mapping manifests
- page-range metadata
- audit results

Use `docs/material_manifest_2026-06-22_120d.md` to see which task expects which local material and page range.

Local generated files remain under:

```text
task_materials/
sessions/
blackboard/
data/
```

These directories are intentionally ignored by git except for README/placeholders.
